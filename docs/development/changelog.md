::: tip 说明

:::

## 如何查看更新日志

1. **在线查看**: 访问 [GitHub 仓库中的 CHANGELOG.md](https://github.com/shawicx/scx-api-tool/blob/main/CHANGELOG.md)

2. **本地查看**: 直接查看项目根目录下的 CHANGELOG.md 文件

## 版本管理

该项目使用 [changesets](https://github.com/changesets/changesets) 进行版本管理，遵循 [Conventional Commits](https://www.conventionalcommits.org/) 规范。

### 版本号格式

- **主版本号**: 不兼容的 API 修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 变更类型

- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式化（不影响代码运行的变动）
- `refactor`: 重构（既不是新增功能，也不是修改bug的代码变动）
- `chore`: 构建过程或辅助工具的变动

## 发布历史

所有的版本发布历史和详细变更记录都维护在项目根目录的 CHANGELOG.md 文件中。
