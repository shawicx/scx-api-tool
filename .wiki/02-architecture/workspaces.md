## 页尾：import 聚合口径说明

本页第 3 节所展示的「import 点数」在本次数据中**没有任何取值**（依赖边为空），因此本页不给出针对该项目的实际聚合结论。

仅就口径本身需注意两点通用限制，供后续补充数据时对照：

- **相对 import 解析**：跨包引用需先将相对路径解析到目标包，解析失败或被跳过时会低估包间耦合。
- **动态加载盲区**：运行时动态加载（非静态 import 语句）不会被静态扫描捕获，可能遗漏真实依赖。

上述两点为方法层面的限制说明，不构成对本项目依赖关系的判断；本项目在这两方面的具体情况属「待确认」，需补充 import 明细数据后另行核实。
